# Keys, Keys, Keys.

*Auteur* : Zlippy
*Difficulté* : Facile

![C00lK1d](https://media1.giphy.com/media/111ebonMs90YLu/giphy.gif)

Une console de salon blanche du milieu des années 2000, célèbre pour ses manettes à détection de mouvement, a été brièvement « empruntée » à son propriétaire.

Un dump partiel de son stockage externe vous est fourni.

Votre mission :

    - Identifier le nom du jeu auquel il joue.

    - Retrouver un second fragment de flag dissimulé quelque part dans les artefacts.

Format du flag : BZHCTF{NomDuJeu_artefact}

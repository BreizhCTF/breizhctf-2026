# Weaponised Polyglot

- **Auteur** : [Shynif](#)
- **Catégorie** : Misc
- **Difficulté** : Moyen

## Description

Il y a tellement de beaux langages de programmation dans ce monde, et chacun a
ses petites particularités qui n'attendent qu'à être exploitées. Le challenge
propose un runner multi-langages : à vous d'écrire un *polyglot* qui s'exécute
différemment selon l'interpréteur ciblé pour déclencher le comportement
vulnérable et récupérer le flag.

## Infra

- Instance dynamique par équipe.

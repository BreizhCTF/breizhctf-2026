# 📜 Règles

## 🧠 Présentation

Ce challenge est une mise en situation réelle basée sur le processus [GitHub Security Advisory (GHSA)](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/fix-reported-vulnerabilities/creating-a-repository-security-advisory).
Vous devez identifier une vulnérabilité réelle dans un dépôt GitHub, la corriger, puis la divulguer de manière responsable via un GHSA.

Note :

- Vérifiez que le dépot est public, que le GHSA est disponible sur ce repo, et que la vulnérabilité n'est pas déjà signalée.
- Les vulnérabilités critiques sont encouragées, mais toutes les découvertes valides seront récompensées.

## 🎯 Objectif

- 🔍 Identifier une vulnérabilité exploitable réelle
- 🛠️ Proposer un correctif fonctionnel
- 🛡️ Créer un [GitHub Security Advisory (GHSA)](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/fix-reported-vulnerabilities/creating-a-repository-security-advisory)
- 🤝 Ajouter l’organisation **BreizhCTF** comme collaborateur (demander sur discord un membre disponible et l'ajouter au GHSA).
- 📤 Soumettre l’ID GHSA sur Discord avec votre nom d'équipe

## 📦 Périmètre

- Chaque équipe doit choisir **un seul dépôt GitHub**
- Le dépôt doit avoir au minimum **1 mois d’existence**

## ⚠️ Règles

- ❌ Aucun autre projet externe n’est autorisé
- 🚫 Interdiction de spam ou d’abus envers les mainteneurs
- 🔒 Aucune divulgation publique avant coordination
- 🧾 Seules les vulnérabilités présentes dans le dépôt choisi sont valides

## ❌ Invalidation

Le challenge peut être invalidé en cas de :
- vulnérabilité invalide ou non exploitable
- rapport incomplet ou de mauvaise qualité
- non-respect du cadre ou comportement abusif

## 📤 Soumission

À envoyer sur Discord :
- 👥 Nom de l’équipe
- 🔗 URL du dépôt choisi
- 🆔 ID GHSA (format GHSA-xxxx-xxxx-xxxx)


## 🏁 Validation

Toutes les soumissions sont vérifiées manuellement.
Le flag est attribué après validation du correctif et du GHSA. par l'équipe organisatrice.
Ne pas oublier d'ajouter le reviewer comme collaborateur GHSA pour permettre la lecture du rapport.

# GHSA Responsive Disclosure

Auteur : Zeecka
Difficulté : Facile

## Description

Trouvez une vulnérabilité dans un dépôt GitHub au choix (≥ 1 mois), puis créez un GitHub Security Advisory (GHSA) via le processus officiel.
Le GHSA doit inclure un patch valide. Soumission via Discord avec l’URL du dépôt et l’ID GHSA (l'ajout d'un collaborateur est requis).
Validation manuelle par le collaborateur ajouté.

*Note : Vérifiez que le dépot est public, que le GHSA est disponible sur ce repo, et que la vulnérabilité n'est pas déjà signalée. Les vulnérabilités critiques sont encouragées, mais toutes les découvertes valides seront récompensées.*
